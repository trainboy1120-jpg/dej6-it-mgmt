DEJ6 IT機器管理システム — 使い方（SOP）
このシステムについて
Quip管理表の後継システムです。DEJ6のIT機器（SSP / FS / ZD611 / Avery / Handy / 無線機 / PC / 携帯）479台のステータスをリアルタイムで管理します。
URLはブックマーク推奨：https://trainboy1120-jpg.github.io/dej6-it-mgmt/
STEP 0 — 初回セットアップ（初回のみ）
  1. 右上の 設定 ボタンをクリック
  2. 以下を入力して「保存して接続」：
    Supabase URLhttps://tetigwcotdqgkwfswbyc.supabase.co
    API Key※ IT POCメンバーに確認してください（anon public key）
    担当者エイリアス自分のAmazonエイリアスを入力（例: sakrhiro）
  3. 右上のバッジが 接続済み になれば完了

STEP 2 — 修理フロー（ステータスの流れ）
正常 修理中 SIM起票済み （SSPのみ） Zebra登録済み 発送済み 修理完了 正常
ステータスやること入力項目注意点
修理中 機器の不具合を発見した時、最初に設定 不具合カテゴリー・不具合詳細・担当者 —
SIM起票済み 社内SIM（t.corp）にチケットを起票したら設定 SIM URL（必須）・担当者 FSはこのステップをスキップしてZebra登録済みへ
Zebra登録済み Zebraポータルに修理登録したら設定 RMA番号（必須）・担当者 備考欄に「スワップ禁止」と記入すること（必須）
発送済み ヤマトで発送したら設定 発送日（必須）・伝票番号・RMA番号・担当者 Slackプレビューが自動生成 → #dej6-it-poc にコピー送信
修理完了 Zebraから機器が返却されたら設定 返却日・担当者 Slackプレビューが自動生成 → #dej6-it-poc にコピー送信
正常に戻す 修理完了後・再稼働時に設定 なし RMA・シリアル等の修理関連データはクリアされる
STEP 3 — ステータス更新の操作手順
  1. テーブルで対象の機器行をクリック（どこをクリックしてもOK）
  2. 「ステータス更新」モーダルが開く → 現在の機器情報を確認
  3. 新しいステータスボタンを選択（例: 修理中）
  4. 表示されたフォームに必要事項を入力
  5. 「発送済み」「修理完了」の場合：Slackプレビューを確認 → コピーして #dej6-it-poc に貼り付け ボタンでコピー → Slackに貼り付けて送信
  6. 保存する ボタンをクリック → テーブルが自動更新される
保存前にモーダルを閉じると変更は破棄されます。必ず「保存する」まで操作してください。
よくある質問（FAQ）

初回は設定が必要です。右上「設定」ボタン → Supabase URL と API Key を入力 → 「保存して接続」。API KeyはIT POCメンバーに確認してください。

FSはSIM（社内チケット）の起票が不要です。修理中 → Zebra登録済み → 発送済み → 修理完了 → 正常 の流れで進めてください。SIM起票済みを選ぶと警告メッセージが表示されます。

Zebraの修理では機器交換（スワップ）が行われることがあります。Amazonの資産管理上、同一シリアル番号の機器が戻ってこないと管理が崩れるため、必ず備考欄に「スワップ禁止」と記入してください。

各行の右端にある ボタンをクリックすると、その機器の全ステータス変更履歴が時系列で確認できます。

ブラウザのlocalStorageに保存されています。同じPC・同じブラウザなら再入力不要です。別のPC・別のブラウザでは初回設定が必要です。シークレットモードでは保存されません。
